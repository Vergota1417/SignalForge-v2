# SignalForge Stage-0 Data Feasibility Audit

## Executive conclusion

SignalForge can truthfully calculate conventional price/volume-bar features from its existing centralized candle architecture: higher-timeframe and completed intraday structure, Wilder ATR, pivot-derived support/resistance, OHLCV relative activity, simple range position, and broad-market/limited curated sector-relative context. These results must retain their actual labels: candle structure, bar volume, OHLCV-derived activity, or estimated bar-based volume profile.

The repository does **not** show connected sources for news, company fundamentals, options positioning, trade-condition bid/ask classification, order-book depth, or market-by-order events. True delta, footprint, absorption, L2/MBO, and GEX therefore cannot be calculated from current inputs and must be `NOT_AVAILABLE`, never inferred from OHLCV.

Equity opening/session-range models already exist, but are explicitly shadow-only and require equity-specific validation before production use. POC/VAH/VAL can be researched from aggregate bar OHLCV only as a declared allocation model; it is not an exact traded-at-price volume profile and must not be presented as one.

No provider or application network calls were made for this audit. Findings are based on repository evidence only. Current provider plans, endpoint entitlements, exchange coverage, adjustment behavior, and real-time/delayed status require external verification before implementation or budgeting.

## Classification key

- `AVAILABLE`: current raw inputs and architecture are sufficient for a truthfully labeled calculation.
- `ADAPTABLE`: inputs largely exist, but methodology, coverage, or equity validation must be completed before production reliance.
- `NEW_SOURCE_REQUIRED`: the current repository has no demonstrated input/source sufficient for the result.
- `RESEARCH_ONLY`: may be calculated as a clearly labeled hypothesis/shadow feature but is not validated production evidence.
- `DO_NOT_SYNTHESIZE`: required evidence cannot truthfully be reconstructed from current OHLCV/quote inputs.

These recommendations describe data feasibility, not permission to affect `BUY NOW`. Production authorization remains owned by the hard guardrails.

## Current architecture observed

- `src/constants.js` defines candle roles presently reachable through named UI timeframes: 5-minute (one regular session), 15-minute (five regular sessions), 1-hour, daily, and weekly, with cache TTLs from 60 seconds to one hour.
- `src/market-data-gateway.js` centralizes cached candle acquisition and supports configured Alpaca and Twelve Data fallbacks. Both paths normalize to timestamped OHLCV bars and write the shared D1 market cache. The gateway also supports symbol/asset discovery; it does not expose news, fundamentals, options, trades, quotes-at-bid/ask, depth, or MBO events.
- `src/market-quote-gateway.js` obtains price, daily volume, average volume, and relative volume for Radar. This is quote/snapshot participation data, not order flow.
- `src/twelve-data-provider.js` requests `time_series` OHLCV and symbol search. `src/provider-usage.js` applies purpose accounting plus a conservative Twelve Data minute guard; `src/db.js` enforces the default 700-request daily ceiling.
- `src/analysis.js` already implements Wilder ATR, local pivot structure, weekly typical-price/volume AVWAP, and time-of-day 15-minute RVOL. Its intraday logic correctly describes price response and participation, not aggressor-side executions.
- `src/opening-range.js`, `src/session-range.js`, and `src/activity-rhythm.js` implement completed-15-minute equity session hypotheses and explicitly mark them shadow-only/non-authoritative.
- `src/benchmark-context.js` has SPY plus a curated mapping for a limited core list to sector/industry ETF proxies. `src/benchmark-loader.js` may load up to three distinct benchmark candle series per symbol unless already preloaded/cached.
- `public/api-request-policy.js` centralizes browser safe-read reuse at roughly five minutes and exact cache-only historical recovery at roughly 30 minutes. Dashboard blocks must consume centralized master state and must not add their own provider calls.

## POC / VAH / VAL implementation boundary

There are two materially different products that must not share an unqualified label:

1. **Exact or trade-derived profile:** aggregate actual executed size into price bins for a declared session/fixed range, choose POC from maximum volume, and compute value area using a documented expansion/selection algorithm. This requires trades-at-price or provider-supplied volume-at-price data not shown in the repository.
2. **OHLCV bar-allocation estimate:** allocate each bar's aggregate volume to one price, uniformly across its range, or through another declared heuristic. This can use current candles but is underdetermined. Results may be useful for research/sensitivity analysis only and must be labeled estimated.

Any estimated profile should expose at least source timeframe, range anchors, bin/tick size, allocation rule, value-area percentage, tie-breaking rule, covered volume/bars, regular-versus-extended session policy, calculation timestamp, and sensitivity to alternative reasonable bin/allocation choices. If materially different reasonable choices move POC/VAH/VAL, the result lacks production-grade evidence stability.

## Freshness and canonical-data implications

- ANALYSIS calculations should use one canonical completed higher-timeframe dataset, not whichever chart horizon the user selected.
- EXECUTION evidence should be based on explicitly completed 15-minute bars. A five-minute quote/price pulse may update location and risk but cannot create a new completed-bar participation result.
- BENCHMARK series must share the stock snapshot's effective cutoff. A fresh stock series compared with stale ETF series should be `PARTIAL`/stale, not silently accepted.
- Every derived result needs provider/source, source timestamp, calculation timestamp, snapshot ID, bar interval/count, freshness, missing inputs, and whether it can affect execution.
- Provider fallback is useful for availability, but calculation snapshots should disclose provider changes and adjustment/session semantics; silently splicing heterogeneous histories is unsafe.

## Request-budget implications and priorities

The current hard ceiling is 700 provider requests/day, with the documented Radar quote maximum already consuming up to 135 requests per market day before promotions, execution checks, holdings, market-data loads, and research. Therefore:

1. Derive ATR, pivots, premium/discount, relative activity, and any research-only profile from the same canonical cached datasets; do not fetch a separate series per Dashboard block.
2. Preload and share SPY/sector/industry ETF datasets across symbols and snapshots. The current per-symbol benchmark loader can otherwise require up to three cold-cache requests for each analysis.
3. Do not add multiple lookback requests solely to populate profile or chart overlays. Choose a canonical source dataset and persist/reuse it.
4. Treat news, fundamentals, options, trades, and depth as new acquisition programs with named purpose, entitlements, bulk/batch behavior, storage, fallback, and worst-case request/event envelopes. They cannot safely be hidden inside the existing candle quota.
5. Streaming microstructure is not meaningfully budgeted as `requests/day`; it requires separate event-rate, bytes/day, reconnect/backfill, sequence-gap, storage-retention, and exchange-entitlement budgets.

## Recommended Stage-0 boundary

Proceed using current shared data for completed-bar OHLCV structure, ATR, pivot-derived levels, and truthfully labeled relative activity. Continue equity opening/session concepts and any OHLCV-estimated volume profile only as shadow research until independently validated. Treat sector mapping as partial and explicitly unavailable for unmapped symbols.

Keep news, fundamentals, and GEX unavailable until purpose-built, externally verified sources are approved. Keep true delta, footprint, absorption, L2, and MBO unavailable; none can be synthesized from existing candles without fabricating evidence.
